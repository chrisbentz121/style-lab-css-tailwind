# STYLE LAB — CSS ⇄ Tailwind
Página estática (HTML + CSS + JavaScript). No necesita Node, npm ni compilar.

**Abrir:** doble clic en `index.html` (o clic derecho → Open with Live Server en VS Code).

**Publicar en GitHub Pages:** sube la carpeta a un repositorio → Settings → Pages → Deploy from a branch → `main` / `/ (root)`.

- `js/gist-data.js`: todas las filas del gist darwinyusef/212ab5c3414bd99fd3658fbc8e63a022
- `js/app.js`: convierte cada fila en una clase CSS real y las usa en la página (sección Code Atelier)
